# 合成器浪潮配方

验证情况：做过一首（《时候未到》），第一版作者听后的评价是「一般，爆炸感和往复回环叠加的氛围完全没体现」，下面的写法包含据此做的修正；修正版还没有被人听过确认。

## 一句话气质
夜晚开车：一个稳稳的脉搏一直往前推。适合「不服气、憋着一口气、还没到见分晓的时候」。

## 调研来源
- 《怪奇物语》主题曲：一组和弦音用十六分音符上下滚动，底下是心跳式底鼓；音色的明暗一直在慢慢变，这是它不无聊的原因
- Hans Zimmer《Time》：四个和弦重复到底（前两个暗、后两个亮），每轮加一层，从不撤
- 通用技法：切断式混响军鼓；底鼓压其他声音（侧链）；108–118 BPM；A 小调 / D 小调常见

## 基本参数
- 速度 112 BPM，`swing: 0`（不摇摆，要机械的直）
- 和弦：Am – F – C – G，一小节一个，循环到底
- 深色主题

## 各乐器怎么弹
- **琶音 `arp`**：每小节 16 个音，和弦音上去再下来（8 个音滚两遍）；从头到尾不停。靠 `arpTone` 从 480 慢慢开到 5000+ 来推情绪
- **底鼓**：安静段用心跳（十六分位 0 和 3）；推进段每拍一下（0、4、8、12），每一下都 `duck`
- **贝斯**：安静段每小节两个长音；推进段八分音符踩根音；高潮段在弱拍加八度跳
- **军鼓 `gsnare`**：第 4、12 位
- **踩镲**：先八分音符，再十六分音符，是最便宜的「加一层」
- **铺底、主旋律**：最后才进。主旋律长音为主，句尾往上

## 段落（《时候未到》，37 小节约 82 秒）
| 小节 | 段落 | 加了什么 |
|---|---|---|
| 0–3 | 前奏 | 心跳 + 很闷的琶音 |
| 4–11 | 第一幕 | 贝斯长音；琶音变亮 |
| 12–23 | 第二幕 | 12 鼓和八分贝斯，16 铺底和十六分踩镲，20 主旋律 |
| 24 | 停顿 | 前三拍军鼓滚奏往上顶，第四拍全空 |
| 25–32 | 第三幕 | 全部回来，主旋律加低八度，后四小节换上行旋律，停在没解决的音上 |
| 33–36 | 结尾 | 只剩琶音和心跳，然后直接停 |

## 踩过的坑
- 琶音默认音量偏小，力度要给到 1.3–2 才听得见；第一幕贝斯要压到 0.5 左右，否则一上来就满了
- 光加乐器不会变响：压缩器和 `duck` 会把音量抹平。高潮段把 `duck` 深度从 0.4 减到 0.3，并把铺底和主旋律力度提上去
- 琶音在音符区里是很小的点，这是正常的

## 画面（2026-11-12 补）
不要用这个风格的标配视觉（紫橙渐变、发光落日、网格地平线）。作者明确否定过，评价是「AI 味太浓」。画面按 `visuals.md` 的原则另行设计，和音乐风格脱钩。

## 第二版的修正
- 琶音必须叠层、带回声、分左右，单条干琶音撑不起氛围。用底座里的 `arp`（带 `pan`）、`arpEcho`、`echoFb` 来做。
- 高潮前必须有「抽空低音 + 拧紧 + 空拍」，高潮用 `boom`、`saw`、深 `duck`。只加不减做不出爆炸感。
- 自检时除了看各段平均音量，还要看「高潮前一段」和「高潮」的落差（这首是 -22.5 → -16.4）。
