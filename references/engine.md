# 模板和底座怎么用

`assets/template/` 里有两个文件：`index.html` 是「这首歌」，`engine.js` 是底座。做新歌时复制整个文件夹，只改 `index.html` 里「这首歌」那一段，底座不动。

**模板的样子优先。** `visuals.md` 里讲的是道理；版面、图例位置、按钮这些已经在模板里定好的东西，以模板为准，不要为了对上某句描述去改底座。

## 「这首歌」那一段有五块

1. **和弦**：每个和弦写成 `{ name, n: [电钢琴弹的四个音], b: 贝斯的根音 }`，再写一个 `chordAt(小节)` 返回这一小节的 `[前半, 后半]`。
2. **旋律**：每个音是 `[小节偏移, 十六分位, 音高, 时值]`。
3. **编曲** `arrange(kit)`：一个小节一个小节地安排每件乐器弹什么。
4. **画纸上那根线** `path(env)`：返回每一刻笔在哪，格式是 `[x, y, 粗细, 颜色]` 的数组，每秒 `env.HZ` 个点。样板里有手抖、粗细变化、惯性那几行，**改线往哪走的时候把这几行留着**，那是这根线像手画的原因。
5. **交给底座的配置** `createEngine({...})`：曲名、风格标签、速度、总小节数、分段、音符区底色。

## 底座里现成的东西

写歌前扫一眼，别重复造。

- **乐器**：`ep` 电钢琴、`bass` 贝斯、`lead` 主旋律、`pad` 铺底、`saw` 一堵墙似的锯齿、`bell` 铃、`ping` 信号音、`arp` 琶音（可分左右声道）、`boom` 砸下来的超低音、`riser` 往上拧的音、`breath` 气声、`kick` / `snare` / `hat` / `rim` 一套鼓。
- **旋钮**：`tone`（整体明暗，用来做「变闷」和「擦亮」）、`arpTone`（琶音明暗）、`arpEcho` / `echoFb`（琶音回声）、`duck(t)`（底鼓把贝斯和铺底压一下）。
- **画纸**：`lineArt`（一根线，可带小点）、`textArt`（把字放进画纸，可垫一个意象）。
- **歌词栏**：`lyrics: [[文字, 出现的小节], ...]`，最下面滚动的小字；有它就不画图例。
- **配置**：`theme`（深色或浅色）、`colors`（各乐器颜色）、`rollColor`（音符区底色随段落变）、`rollOverlay`（在音符区上再画一层，比如起雾）、`fade: false`（结尾不淡出）、`swing`（摇摆的量，0 是不摇摆）、`badge`（封面上播放键的位置，注意避开线）。
- **分段** `sections: [['前奏', 4], ['第一幕', 12], ...]`：数字是这一段结束的小节。自检脚本按这些名字分段报响度；名字里带「前奏」「过门」「尾」的不参与幕与幕的比较。

## 调试用的钩子

页面加载后可以在控制台或无头浏览器里用：

- `__draw(秒数, false)`：画出某一刻的画面。`__draw(0, true)` 画封面。画布的 id 是 `c`。
- `__check()`：返回峰值、无效采样数、各段的峰值和平均响度。`render.cjs --check` 用的就是它。
- `__render()`：离线渲染整首歌，返回音频数据。

## 底座目前没有的

遇到时告诉用户，不要悄悄改底座：

- 吉他等别的乐器舞台（民谣见 `style-folk-guitar.md`，要自己画）
- 暂停后从原处继续、拖动或按键跳转
- 给文字里的细节声单独起名的灯
- 按实际音域自动缩放的琴键

需要新音色时加在 `engine.js` 里，并让它也记一笔音符事件，这样画面才看得到它。
