# 踩坑清单（按症状查）

每一条都真实发生过。左边是用户会说的话或你会看到的现象。

## 用户说了一句，但你不知道具体哪里不对

| 用户说 | 多半是 | 怎么办 |
|---|---|---|
| 「后面有点单调」「太重复了」 | 用原样重复去表达「重复」 | 旋律不动，让落点、和弦、音色在变；最后一遍唱到一半断掉。先问清是哪一段 |
| 「爆炸感没出来」「一般」 | 高潮前没有抽空，只加不减 | 高潮前两小节抽掉底鼓和贝斯，空一拍再砸下来；看「高潮前一段」和「高潮」的响度落差 |
| 「太粗糙了，精致一点」 | 乐器是凭印象画的 | 查真乐器有哪些细节，加它本来就有的，不加花纹 |
| 「形状不对」 | 比例不对，或者裁掉了一半 | 按真实尺寸换算，整件画出来 |
| 「AI 味太浓」 | 套了这个音乐风格的标配视觉 | 画法从这段文字的情绪里来，和风格脱钩 |
| 「跟人家那个太像了」 | 照搬了参考图的标志性元素 | 只留它的思路，元素换成从用户文字里长出来的 |
| 「这个是什么含义」 | 画面没立住 | 换掉，不要解释 |
| 「视觉重心不对」「被分割了」 | 几块一样大一样重，中间有缝 | 连成一整块，画纸占大头，音符区底色调淡 |
| 「它抢了视觉重心」 | 控件或进度条成了第二个主角 | 借用画面里已有的东西，或者干脆不要 |
| 「缺少了音符按下、线条留痕的美感」 | 把乐器换成了别的（比如演奏的人） | 换回乐器。这是底线 |
| 「不是我想要的，还是之前那版」 | 按描述重新设计了 | 拿那一版的文件当底子改 |
| 「幅度小一点」 | 效果做夸张了 | 照真实的幅度来 |

## 声音

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 峰值超过 1 | 乐器叠在一起 | 调低总音量，目标 0.9 以下，留余量 |
| 不爆音但整体很小声 | 某一下鼓的瞬时峰把整体压住了 | 降那一下鼓，或把压缩器调紧；整首平均响度不要低于负 16 分贝左右 |
| 加了做旧、过载之类的效果后爆音 | 效果会把电平推高 | 加完重新压回原来的响度，这样前后对比才公平 |
| 各幕响度差不到 1.5 分贝 | 加乐器不等于变响，压缩器会抹平 | 靠各乐器的力度把台阶拉开，不要直接乘音量系数 |
| 手机外放刺耳 | 主旋律太高 | 不超过 MIDI 88；叠八度往下叠 |
| 手机上听不到贝斯 | 根音太低 | 不低于 MIDI 36 |
| 琶音听不见 | 默认音量偏小 | 力度给到 1.3 以上 |
| 低音越叠越浑（吉他） | 同一根弦弹了新音，旧音没掐掉 | 新音响起时把同弦的旧音很快收掉 |
| lo-fi 听起来太干净 | 没做旧 | 加黑胶底噪和噼啪、音高轻微晃动、轻度过载、削掉最高和最低频 |

## 画面

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 线像心电图、像股票走势 | 线的高度直接等于音高 | 每一幕的状态决定线往哪走，音高放慢后只加一点起伏 |
| 线是一格一格的台阶 | 没有惯性 | 让笔慢慢滑向目标位置 |
| 封面是空的，或和开头一样 | 画纸只画了瞬间，没留下痕迹 | 让走过的地方留下来 |
| 画纸有一整块空着 | 构图没铺开 | 调整线的起点和走向；「困住」的情绪除外 |
| 被按下的琴键看不出来 | 颜色太淡 | 用乐器的颜色点亮 |
| 音符挤成小方块，看不出长短 | 下落的距离太短 | 留够高度，至少能让一拍的音看出长短 |
| 图例被视频平台的进度条盖住 | 放在了画面最底部 | 重要的东西别放最下面一条 |
| 浅色的音符看不见 | 音符区底色调淡之后撞色了 | 换掉白色这类浅色 |
| 原文的细节从幕名、灯名里漏出来 | 只藏了正文 | 幕名和灯名用中性的词 |

## 页面和视频

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 页面一打开就报错 | 没播放时也要画封面，但还没拿到音符记录 | 页面加载时先空排一遍谱（模板已处理） |
| 录制时报安全错误，或录出来是黑的 | 画布上用了外部图片文件 | 把图片转成内嵌的数据再用 |
| 录出来是 webm，平台不收 | 没检查浏览器支不支持 mp4 | 优先 mp4；最稳的是用 `render.cjs` 逐帧渲染 |
| 实时录屏掉帧 | 录屏本来就不稳 | 用 `render.cjs` |
| 自动测试时用户听到后台在响 | 无头浏览器在播放 | 自检用离线渲染，不实际出声 |

## 协作

| 现象 | 怎么办 |
|---|---|
| 做到第三版才发现用户不想露原文 | 「文字能不能出现」在做画面之前问 |
| 没等确认就换了方向，被打断 | 换画面、换风格、重写某一段之前，先用一两句话说清要改成什么 |
| 用户否掉一个做法后，你猜了一个替代方案，又被否掉 | 被否了先问清楚想要什么 |
| 用户想退回上一版，文件已经被覆盖 | 每次大改之前另存一份 |
| 用户提了一个新点子（比如加几个演奏的人），做了好几轮才发现把核心挤掉了 | 动手前先对照「音符落下、线条留痕」，保不住当场说 |
| 让另一个 AI 按文字描述做，样子总是不一样 | 给它模板，不要只给描述 |
