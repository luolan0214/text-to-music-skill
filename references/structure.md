# 从文字到结构

这一步决定歌的好坏。先做完给用户看，用户点头再写。

## 目录

## 怎么拆幕

1. 找出文字里的**情绪转折**。每一段情绪是一幕，通常两到四幕。只有一种情绪就做一幕加前奏尾奏，不要硬拆。一句话的素材也能拆：一句对着某个人说的「我把自己关起来了」可以是三层，把自己关起来、叹出一口气、对着那个人喊。
2. 给每一幕配一个**音乐手法**，手法要能用一句大白话解释。
3. 从文字里至少挑**一个具体的细节变成声音**：「下雨」是雨声在那一句进来，「收衣服」是衣架碰晾衣杆的一声「嗒」，「按了一下车铃」是全曲只响一次的铃。可以多做几个，但不要多到抢旋律。
4. 把结果列成表给用户看：

| 段落 | 文字里的情绪 | 音乐怎么表达 |
|---|---|---|

同时说明那根线在每一幕往哪走（见 `visuals.md`）。

素材是图片时：读它的主色、场景、明暗，用来定配色和意象；默认做成一种情绪的歌，除非用户给了变化。

## 先看大师怎么做

读懂了情绪、定了风格之后，写任何一个音之前，先查行业里最好的人是怎么做出这种效果的。不查的话，只会用自己已经会的那几招，每首歌听起来都像上一首。

1. 先看 `references/research-*.md` 里有没有同类情绪的笔记，有就直接用。
2. 没有就上网查。把情绪翻译成能搜到的问题：谁以这种效果出名，他们具体怎么做的。优先找本人访谈和拆解分析。
3. 提炼出三四条**能直接搬进代码的手法**，每条写明：谁、怎么做、为什么有这个效果、在这首歌里怎么用。
4. 用大白话讲给用户听，再放进分幕表。
5. 把笔记存成 `references/research-<情绪>.md`。

## 情绪 → 手法对照表

都是做过的歌里验证过的。

| 情绪 | 手法 | 为什么有效 |
|---|---|---|
| 舒展、日常 | 完整律动，旋律句尾不落到主音 | 好听但悬着，给后面留空间 |
| 卡住、重复、没进展 | 同一句旋律反复，每遍落点更低；和弦来回转、始终不落到主和弦；整体越来越闷 | 旋律不动、周围在变，才是困住而不是无聊 |
| 撑不下去 | 最后一遍旋律唱到一半断掉；鼓和贝斯一件件撤走 | 没唱完比唱完更让人难受 |
| 松下来、不赶了 | 鼓打半速，贝斯一小节只走一两步，句间多留空 | 放过自己和被困住不同，要松不要闷 |
| 转折、被什么打动 | 一小节过门：军鼓滚奏、上升的气声、声音一下擦亮 | 像把起雾的玻璃擦干净 |
| 叹一口气 | 律动整个停住，一声呼气，再擦亮 | 停下来的那一拍最重 |
| 打开、有希望（偏乐观，慎用） | 升一个调；前半复用第一幕的旋律，后半换一段向上的新旋律；加铺底和铃 | 复用让人认出还是那个生活，新旋律才是真的往前走了 |
| 喊一个人、没人答 | 两个往下落的音喊几次，一次比一次轻，最后一次只喊出一个音；每次后面空一小节，只有自己的回声 | 空着的那一小节比任何音都响 |
| 人不在了 | 原来有两个声部一问一答，后来只剩一个，答的那句空着 | 位置还在，人不在 |
| 憋着一口气、越来越藏不住 | 一串不停滚动的音，音色从很闷慢慢变亮 | 同一个东西一直在，只是越来越压不住 |
| 不泄气、一点点攒 | 和弦从头到尾不变，每几小节加一层乐器，一次都不撤 | 只加不减本身就是不往回退 |
| 爆发 | 爆发前抽掉底鼓和贝斯，军鼓越敲越密，空一拍，再一起砸下来 | 爆发感来自落差，不来自音量 |
| 还没赢、时候未到 | 结尾撤到只剩最初的脉搏，然后直接停，不淡出、不落回主和弦 | 停在还在走，而不是到了 |
| 没有痊愈，只是「或许」 | 落回主和弦但收得轻，不做大结局 | 文字没说的，音乐不要替它说 |

每做成一种新的，补一行。

## 判断方案好不好的三条

- **音乐的乐观程度不超过文字。** 拿不准时指出来让用户定。例子：文字的落点是一句带「或许」的话，重音在「或许」上，最后一幕就不能是全曲最满最亮的大团圆。
- **想表达「不变」，要靠周围在变。** 把「卡住、没有进展」写成同一句原样重复四遍，用户的评价是「后面一部分过于单调和重复」。
- **幕与幕的差别要听得出来。** 乐器的增减、音区、疏密，至少变一样。差别要从编配里长出来，直接给某一幕乘一个音量系数只是让数字达标。情绪最重的一幕不一定最响，安静也可以是最重的。

## 写歌时的几条硬约束

- 旋律要唱得出来：相邻的音为主，句间留换气的空，不超过一个半八度。
- 时长含尾音 60–90 秒；文字很短就靠近 60 秒，不要为了凑时长重复段落。
- 主旋律超过 MIDI 音高 88 在手机外放上偏尖；叠八度往下叠，不往上叠。
- 贝斯根音不要低于 36，手机喇叭放不出来。
- 各风格的和弦、弹法、速度见对应的 `style-*.md`。没有配方的风格，先把打算用的速度、和弦走向、各乐器弹法用大白话讲给用户，做成后写一张新配方。
