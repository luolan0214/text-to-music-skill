# 民谣吉他配方

验证情况：做过两首（《朝西的阳台》《还响》）。吉他的画法和琴弦的振动是作者逐轮纠正过的；吉他的音色是代码模拟的拨弦，只测过音准和余音，**像不像还没有被人听过确认**。

这份配方和 `SKILL.md`、`visuals.md` 冲突的地方，以配方为准。注意：模板底座目前只有琴键，没有吉他；做民谣要在歌的页面里自己画吉他，或者不用模板从零搭。

## 这是什么，不是什么

目标是一首有民谣唱作人气质的吉他小品：一把木吉他，一条像在说话的旋律，乐器很少，留白很多。

开工前对齐时，SKILL.md 里「真实乐器的质感做不到」那句要改口：吉他是用代码模拟拨弦，能做出来，但像不像只能由用户来听。

它做不出某位歌手的味道。唱作人最有辨识度的是嗓音和歌词，这两样代码做不了。只学写法上的特征，不照搬任何一句现成的旋律。

## 依据

和弦的用法参考了一首华语民谣弹唱的和弦谱（只查到这一首的完整谱），所以下面分两类标注。

**查到的事实**（来源：公开的吉他和弦谱和调性说明）
- 原调 E 大调，吉他用 C 调指法、变调夹夹四品（所以谱上写的是 C 调的和弦，实际听到的高四个半音）。
- 全曲只用五个和弦：C、Am、F、G、Em，换成级数是一、六、四、五、三级。没有七和弦，没有离调和弦。
- 主歌前半是「C Am｜F C G」重复，后半转到「Am Em｜F C」，以「F G」收住。
- 副歌换和弦更慢，一句一个和弦（C、Am、F、C），比主歌更开阔。

**推断和通用做法**（没有逐条查证）
- 速度偏慢，四四拍。网上的 MIDI 版本标 100 到 130 不等，彼此不一致，不可信；按听感取每分钟 68 到 76 拍。
- 主歌用分解和弦，副歌可以换成轻扫。
- 旋律音域窄，以相邻的音为主，句子像说话。

## 写法

**和弦**
- 只用调内的一、六、四、五、三级这五个三和弦。不要七和弦、九和弦（这一条覆盖SKILL.md 附录 B 的约定）。想要一点颜色，用吉他上常见的挂二或加九即可，一首歌里最多一两处。
- 主歌两拍换一个和弦，副歌一小节甚至两小节一个和弦。和弦换得慢，听起来就开阔。
- 用 G 大调或 C 大调的指法来排音，这两个调的五个和弦几乎都是开放把位，最像民谣吉他。想要别的实际音高，就整体移调，相当于夹变调夹。
- 和弦的按法照下面的表排，从六弦到一弦，数字是 MIDI 音高，「×」是不弹。不要自己发明吉他弹不出来的排列。

| 和弦 | 六弦 | 五弦 | 四弦 | 三弦 | 二弦 | 一弦 |
|---|---|---|---|---|---|---|
| G | 43 | 47 | 50 | 55 | 59 | 67 |
| Em | 40 | 47 | 52 | 55 | 59 | 64 |
| C | × | 48 | 52 | 55 | 60 | 64 |
| D | × | × | 50 | 57 | 62 | 66 |
| Am | × | 45 | 52 | 57 | 60 | 64 |
| Bm（G 调的三级，横按） | × | 47 | 54 | 59 | 62 | 66 |
| F（C 调的四级，横按） | 41 | 48 | 53 | 57 | 60 | 65 |
| Cadd9（偶尔用一处） | × | 48 | 52 | 55 | 62 | 64 |
| Gadd9（偶尔用一处） | 43 | 47 | 50 | 57 | 59 | 67 |

**吉他**（主角，从头到尾都在）
- 分解和弦的弹法，八分音符，根音落在拍点上：
  - 一小节一个和弦：根音、三弦、二弦、三弦、一弦、三弦、二弦、三弦。
  - 两拍一个和弦：根音、三弦、二弦、三弦，下一个和弦再来一遍；偶尔把二弦换成一弦，免得太规整。
  - 力度：根音 0.8 左右，其余 0.45 到 0.6，每小节第三拍的那个音稍重一点。
- 六根空弦的音高是 40、45、50、55、59、64（MIDI 音高），和弦的音要落在这个范围里并且符合吉他的把位，不要排出吉他弹不出来的音。
- 每个音让它自然响到底，换和弦时别的弦上的余音可以留着，这是吉他好听的地方。但同一根弦上弹了新的音，旧的音要掐掉（很快地收掉音量），真吉他就是这样，否则低音会越叠越浑。
- 手不是机器：每个音的时间随机错开几毫秒，力度上下浮动一点；给每个音传不同的 `seed`，这样同一个音弹两次波形也不一样。
- 不要十六分音符的摇摆，民谣吉他是平的八分音符（这一条覆盖SKILL.md 附录 B）。
- 副歌可以换成轻扫：一、三拍往下扫全部的弦（从低到高，每根弦错开约 14 毫秒），二、四拍的后半拍往上轻扫最高的三根弦（从高到低）。力度比分解时还要轻，否则六根弦叠起来会很吵。

**旋律**（用一个柔和的音色，不要抢吉他）
- 音域不超过一个八度，以相邻的音为主，可以连着几个音在同一个音高上，像在念一句话。
- 句子从弱拍进来，落在和弦里的音上；句与句之间留足空，让吉他自己弹一会儿。
- 用正弦波加一点泛音、慢起慢收，听起来像口哨或哼唱，不要用合成器味重的锯齿波。

**其他乐器**（越少越好）
- 贝斯只弹根音，一小节一两个音，可以到副歌才进。
- 不要架子鼓。需要律动时用很轻的沙锤（短噪声），或者拍琴箱的一声闷响。
- 副歌可以垫一层很淡的长音（像弦乐或口琴），其余时间不用。
- 不做黑胶做旧，不加回声。可以加一点房间混响，像在屋里弹。
- SKILL.md 里「整体变闷再擦亮」的手法可以用，但吉他不要压得太狠（总低通不低于 3500 赫兹），否则拨弦的亮度没了就不像吉他。
- 音量的主次：吉他最响，旋律比吉他轻一点，贝斯和长音明显更轻。

**结构**
- 主歌、主歌、副歌的叙事结构，不是循环。前奏只有吉他。
- 这个速度下一小节三秒多，90 秒只放得下约 26 小节。参考分配：前奏 2、主歌一 8、主歌二 6 到 8、副歌 8、尾声 2。
- 高潮靠副歌的开阔：和弦换得慢，吉他从分解变成扫弦。副歌会因此自然响一些，但不要再靠加乐器去堆，贝斯和长音加起来不超过两样。

## 画面

SKILL.md 的画面规则照旧，这里只写民谣特有的：下面画一把吉他，而不是琴键。

**图例**里列这首歌实际用到的声音，吉他排第一。没有鼓时，灯那一栏换成实际用到的声音，比如拍琴箱、文字里的细节声；没有就不放。

**吉他整把完整画出来，按真琴的比例。** 裁掉一半、琴颈画粗，看起来就像一把勺子。
- 横躺着：琴身在左，琴颈和琴头向右。
- 琴身是葫芦形：大的下半身朝外，中间收出腰，上半身小一点接琴颈。
- 音孔在上半身、紧挨琴颈；琴桥在下半身，离音孔有一段距离。
- 琴颈很细：琴枕处约 45 毫米，到琴身接合处约 56，只有琴身最宽处的八分之一左右。为了看清六根弦，可以比真琴略宽一点，但不要超过琴身的六分之一。指板一直伸到音孔边。另一端是琴头，长约 180，两侧各三个弦钮。
- 尺寸照一把真琴换算：弦长约 650 毫米，琴枕到琴身接合处（第十四品）约 360，琴身长约 500、最宽约 380、上半身约 285、腰约 240，音孔直径约 100。
- 六根弦从弦钉出发，过下弦枕、琴枕，绕到各自的弦柱上。琴桥处六根弦共宽约 55 毫米、琴枕处约 37，所以弦不是平行的。粗的三根偏金，细的三根偏白，每根下面一道影子。
- 品丝按真实的品距画，越靠近琴头越宽；品位圆点在三、五、七、九品，第十二品是两个。
- 平涂的颜色，像剪纸。默认红色琴身、深棕指板、浅色品丝；画纸里用到的那一点颜色取同一个红，上下呼应。红琴身会是画面里最重的一块，这是作者知情后的选择，SKILL.md「眯眼先看到线稿」那条在这里不适用。
- 细节只加真吉他有的：一道浅色镶边、一层投影、音孔外两三圈饰线、护板（音孔旁细弦一侧的一片水滴形，比琴身深一点，不要画成一团黑）、下弦枕和六颗弦钉、琴枕。
- 吉他要画得够大：横向占满画面宽度的九成，画纸和吉他之间不必留很高的音符区。

**音符落在它实际被按下的位置。** 按弦的音落在它所在那一品的两根品丝之间、落到它那根弦上；空弦的音落在音孔上，六根弦横向各错开一点，免得叠成一团；落到弦上的那一刻就是它响的那一刻，落点亮一下。每个音画成一个深色圆点，后面拖一条很淡的余音，不要照三秒的实际长度画。

这首歌用的是开放把位，音只会落在音孔和靠近琴头的那几品，所以吉他上方会有不少空白。这是真实的，不要为了填满而把音符挪到不对的位置；SKILL.md 自检里「空着的一大块」不算这一块。

**弦照真弦的规律振动**，不要画成一条正弦波：
- 拨之前的一瞬间，手指先把弦勾成一个三角形，尖角在拨弦的位置（音孔上方）。
- 松手后，那个折角沿着弦来回跑，在琴桥和按弦处反弹。做法是把三角形拆成十几个泛音叠加，各泛音保持同相位。真实频率太快，放慢到每秒两三次，肉眼才看得见。
- 越高的泛音衰减越快，所以折角很快被磨圆，最后只剩一条平滑的弧线。低音弦余振长，高音弦短。
- 叠一片淡淡的影子表示弦扫过的范围，上下边缘最清楚，因为弦在最高和最低点停留最久。
- 只有「按住的那一品到琴桥」之间在振，另一段是直的。
- 幅度要小，但在原尺寸下必须看得出：最大约为弦距的六七成，不要碰到相邻的弦。作者要求过把幅度调小，也要求过要像真弦。
- 网上那种弦扭成波浪的视频是手机快门造成的假象，不要照那个画。

**不是吉他的声音**（口哨、哼唱、贝斯、长音）只在图例上亮灯，不往吉他上落。

**试过、被否掉的做法**，不要再走：
- 把吉他裁掉一半、只画琴身一角。作者说形状不对。
- 把口哨、哼唱、贝斯在吉他上方写成几条随时间延伸的线。作者不要这些线。
- 把下面换成一个小舞台，画几个演奏的人，先是代码画，后来用生图工具画、每人两个姿势按音符切换。人画得很精细，仍然被否掉，因为音符只是飘出来就消失，画面从看音乐变成了看乐队。

## 吉他音色的代码

模拟拨弦，已验证：七个音的音准偏差在 4 音分以内，低音弦余音约 3 秒、高音弦约 1.6 秒。直接使用，不要改算法；`vel` 是 0 到 1 的力度。

```js
// 模拟拨弦（Karplus-Strong）：一小段噪声在一根「弦长」的延迟线里来回，每圈被磨掉一点高频，就成了拨弦的声音
function pluckSamples(sr, midi, dur, vel, seed) {
  const f = 440 * Math.pow(2, (midi - 69) / 12), n = Math.floor(sr * dur), out = new Float32Array(n);
  const D = sr / f - 0.5, N = Math.floor(D), frac = D - N, buf = new Float32Array(N + 2);
  let s = seed || (midi * 9301 + 49297); const rnd = () => ((s = (s * 1664525 + 1013904223) >>> 0) / 4294967296) * 2 - 1;
  // 起振：噪声先过一遍低通（力度越大越亮），再减去自己错开一段的副本，模拟拨在弦的五分之一处
  const bright = 0.25 + 0.6 * vel, pick = Math.max(1, Math.floor(N * 0.2)), ex = new Float32Array(N + 2); let lp = 0;
  for (let i = 0; i < N + 2; i++) { lp += (rnd() - lp) * bright; ex[i] = lp; }
  for (let i = 0; i < N + 2; i++) buf[i] = ex[i] - (i >= pick ? ex[i - pick] : 0) * 0.9;
  let mx = 0; for (let i = 0; i < N + 2; i++) mx = Math.max(mx, Math.abs(buf[i])); for (let i = 0; i < N + 2; i++) buf[i] /= mx || 1;
  // 低音弦余音长、高音弦余音短
  const t60 = Math.max(1.2, 4.2 - (midi - 40) * 0.055), g = Math.pow(10, -3 / (t60 * f));
  const damp = 0.5 - 0.12 * vel;                       // 每圈磨掉多少高频
  let w = 0, prev = 0; const M = N + 2;
  for (let i = 0; i < n; i++) {
    const r1 = (w + 2) % M, r0 = (w + 1) % M;          // 最老的两个样本，做小数延迟
    const x = buf[r1] * (1 - frac) + buf[r0] * frac;
    const y = (x * (1 - damp) + prev * damp) * g; prev = x;
    out[i] = x; buf[w] = y; w = (w + 1) % M;
  }
  const rel = Math.min(n, Math.floor(sr * 0.06));       // 收尾，避免咔哒声
  for (let i = 0; i < rel; i++) out[n - 1 - i] *= i / rel;
  for (let i = 0; i < Math.min(n, 40); i++) out[i] *= i / 40;
  for (let i = 0; i < n; i++) out[i] *= 0.5 * (0.5 + 0.5 * vel);
  return out;
}

// 用法：算出一个音的波形，放进 AudioBuffer 播放；返回音量节点，方便在同一根弦弹新音时把它掐掉。
// 时长按余音来定：低音给 4.5 秒，高音 3 秒就够。
function pluck(ctx, dest, t, midi, vel, seed) {
  const data = pluckSamples(ctx.sampleRate, midi, midi < 52 ? 4.5 : 3, vel, seed);
  const buf = ctx.createBuffer(1, data.length, ctx.sampleRate); buf.getChannelData(0).set(data);
  const src = ctx.createBufferSource(), g = ctx.createGain(); src.buffer = buf; src.connect(g); g.connect(dest); src.start(t);
  return g;   // 掐音：g.gain.setTargetAtTime(0, 新音的时间, 0.02)
}
```

三百个音左右，整首离线渲染多花几秒，可以接受。`vel` 同时管音量和亮度，轻弹的音会发闷，所以想让某一段安静，优先减少音的数量，其次才是降力度。

吉他总线：音量约 0.6（六根弦扫下来会叠得很响）；在 110 赫兹和 220 赫兹附近各推高 2 到 3 分贝（琴箱的共鸣），5000 赫兹以上削掉约 5 分贝。
